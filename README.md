# Chinese Chess Web

一个支持人机对弈、好友对战、棋谱复盘与局面分析的中国象棋 Web 应用，使用 React、Go 和 C++ 构建。

保留传统棋盘与棋子的视觉风格，适配桌面和手机。浏览器负责交互，Go 服务管理对局与实时同步，C++ 引擎负责规则计算、搜索和评估。

## 快速启动

准备 Go 1.26、Node.js 24、支持 C++17 的编译器（Clang 或 GCC）、Make 和 Docker Compose。以下命令在项目根目录运行。

```sh
cp .env.example .env
docker compose up -d --wait
make build
set -a
. ./.env
set +a
make run
```

打开 [象棋网站](http://127.0.0.1:8765) 开始对弈。[本地收件箱](http://127.0.0.1:8025) 用于查看注册验证和密码重置邮件。应用启动时会自动应用数据库迁移。首次构建需要下载锁定的前端和 Go 依赖。

## 功能

### 对弈

- **人机对弈**：选择红黑方与计算预算，支持合法落点提示、将军提示、悔棋、认输和继续对局。
- **好友对战**：分享邀请链接，访客申请后由房主确认入座；双方准备后开始，默认每方 10 分钟、每步加 5 秒。
- **对局协商**：PVP 支持双方同意的悔棋与和棋，以及离座、房间关闭和对局结果同步。
- **休闲规则**：处理超时、将死、困毙及重复局面；同一局面三次出现判和，持续将军的一方判负。每份棋谱保留对应规则版本。
- **实时同步**：WebSocket 推送对局状态，支持断线重连、页面刷新与对局恢复。

### 复盘与分析

- **历史对局**：按对局类型分页查看自己的记录。
- **完整复盘**：逐步回放、跳转手数、翻转棋盘、键盘操作与 JSON 棋谱导出。
- **局面分析**：查看引擎评分、推荐着法、主变化和完成深度。
- **整盘分析**：对结束的对局生成分析任务，支持深入分析、暂停与继续。
- **独立练习**：从复盘局面创建新的练习对局，保留来源和历史前缀，原棋谱保持独立。

分析会保留引擎版本、搜索预算、完成深度、评分视角、结果可靠性和局面来源。评估分表示引擎对局面的判断，不能直接当作胜率。

### 账号与管理

- 邮箱注册与验证、登录、密码重置和会话管理。
- 访客受邀参与对局，支持房主审批与访客记录归属流程。
- 个人中心展示对局结果、执子表现、分析统计及使用频率热力图。
- 管理端提供用户封禁与解禁、会话撤销、分析任务暂停和操作审计。

当前部署形态为单实例 Go 服务与 PostgreSQL。管理端应通过受限入口访问；管理员权限通过服务端本地命令授予。

## 技术架构

```text
React / TypeScript
        │
        │ HTTP + WebSocket
        ▼
     Go 服务 ───────── PostgreSQL
        │              对局、棋谱、账号、分析结果
        │ 进程协议
        ▼
     C++ 引擎
     棋盘规则、搜索、评估
```

| 模块 | 技术 | 职责 |
| --- | --- | --- |
| 前端 | React、TypeScript、Vite | 页面、棋盘交互与静态构建 |
| 界面组件 | Ant Design、CSS Modules、共享设计变量 | 统一控件、样式与响应式布局 |
| 路由与状态 | React Router、TanStack Query | 页面导航、查询与版本化状态更新 |
| 服务端 | Go、标准库 `net/http` | API、对局、账号、授权及任务调度 |
| 实时通信 | WebSocket | 对局快照、状态推送与重连 |
| 数据存储 | PostgreSQL、pgx、goose | 持久化、事务与版本化数据库迁移 |
| 象棋引擎 | C++17 | BitBoard、走子撤销、搜索、评估及缓存 |
| 测试 | Go test/race、Vitest、Testing Library、Playwright | 模块、并发、组件和浏览器回归 |

服务端是对局状态的权威来源。客户端根据服务端提供的合法着法交互；命令通过版本检查和幂等标识处理，较旧的响应不能覆盖较新的实时状态。

## 项目结构

```text
chinese-chess-web/
├── web/       # React、交互原型与浏览器回归
├── server/    # Go 服务、管理命令、数据库迁移与集成测试
├── engine/    # C++ 引擎、接口头文件与原生测试
├── assets/    # 棋盘、棋子与落子音效
├── tests/     # 引擎协议测试及固定局面
├── deploy/    # 反向代理示例
└── docs/      # 开发与自托管说明
```

## 开发与部署

- `make build` 构建引擎、服务端、管理命令和前端。
- `make test` 运行原生测试、Go race 检查与前端组件测试。原生协议测试使用 Python 3。
- `make test-e2e` 使用 Playwright 验证运行中的完整应用。
- `make format` 使用 clang-format 统一 C++ 格式。项目采用 Microsoft 风格，函数、类型和控制块的开大括号独占一行。

真实 PostgreSQL 集成测试、本地管理操作和生产配置见[开发与自托管指南](docs/development.md)。
